# 接口协作约定

## 1. 基本约定

- 浏览器统一通过 `/api` 访问业务接口。
- OpenAPI 文档必须与实际实现同步。
- 接口路径、HTTP 方法、请求字段、响应字段、错误码和认证方式必须明确。
- 时间、金额、分页和枚举字段必须采用统一格式。

## 2. 建议响应结构

具体结构由项目骨架确定，但项目内必须保持一致。例如：

```json
{
  "code": "OK",
  "message": "success",
  "data": {}
}
```

错误响应至少区分：参数错误、未登录、无权限、资源不存在、业务冲突和服务异常。不得把内部堆栈、密码或连接信息返回给客户端。

## 3. 分页、时间与金额

- 分页请求和响应字段保持统一。
- 时间统一使用明确时区的 ISO 8601 格式，或在文档中声明固定时区。
- 金额避免使用二进制浮点直接计算，明确单位与精度。
- 枚举值在 OpenAPI 中列出并说明含义。

## 4. 变更流程

接口变更 PR 应写明：

- 变更前后的字段或行为
- 是否向后兼容
- 对应前端页面和后端模块
- 联调与发布顺序
- 必要的迁移或回退方案

## 5. 图片接口

- 图片存储由后端与阿里云 OSS 交互。
- 客户端不得获得长期有效的 OSS AccessKey。
- 数据库存储 ObjectKey 等稳定标识，临时签名 URL 按需生成。
- 明确允许的文件类型、大小、数量和失败响应。
