## 1. 通用约定

### 1.1 基础

- 路径前缀 `/api/v1`；本地后端地址 `http://127.0.0.1:8080`。
- 请求和响应都是 JSON（上传图片除外，用 `multipart/form-data`），编码 UTF-8。

### 1.2 统一响应

```json
{ "code": 0, "msg": "ok", "data": {} }
```

| 字段 | 类型 | 说明 |
|---|---|---|
| code | int | 0 表示成功；其他取值见 1.3 和第 3 节 |
| msg | string | 提示信息，可以直接展示给用户 |
| data | any | 业务数据；没有数据时为 null |

### 1.3 HTTP 状态与通用码

| 情况 | HTTP 状态 | code |
|---|---|---|
| 成功 | 200 | 0 |
| 业务错误 | 200 | 6 位业务码（见第 3 节） |
| 请求不合法（见下方说明） | 400 | 40000 |
| 未登录或 token 失效 | 401 | 40100 |
| 内部口令错误或没配置 | 403 | 40300 |
| 路径不存在 | 404 | 40400 |
| 系统错误 | 500 | 50000 |
| 功能未实现（通用兼容码，不作为搜索接口正常响应） | 501 | 50100 |

返回 400 / 40000 的情况包括：参数校验失败、参数缺失或格式不对、请求体不是合法 JSON、请求方法不支持、上传的请求超过 10MB。

### 1.4 鉴权

- **公开接口**：不需要任何请求头。接口标题后面标了"公开"的就是。
- **登录接口**：
  - 请求头带 `Authorization: Bearer <token>`，token 从登录接口拿。
  - 每访问一次，有效期就续满 7 天。
- **内部接口**：
  - 请求头带 `X-Internal-Key: <口令>`，口令来自配置 `dss.internal.key`。
  - 不认用户 token。

### 1.5 分页

- 请求参数：
  - `page`：从 1 开始，默认 1
  - `size`：默认 10，最大 50
- 响应 data：

| 字段 | 类型 | 说明 |
|---|---|---|
| list | array | 当前页的数据 |
| total | long | 总条数 |
| page | int | 当前页 |
| size | int | 每页条数 |

### 1.6 数据格式

- **ID**：一律用字符串。后端用 MySQL `BIGINT AUTO_INCREMENT`、Java `Long`；现阶段可能很短，将来超过 JS 安全整数范围时也不丢精度。路径参数直接写十进制字符串。文中较长示例 ID 仅作格式示意。
- **金额**：整数，单位分。比如 `990` 表示 9.90 元。
- **时间**：`yyyy-MM-dd HH:mm:ss`，东八区。
- **枚举**：英文大写字符串，取值见第 2 节。排序参数 `sort` 是例外，用小写代码。
- **图片**：请求里传 fileId（由上传接口返回）；响应里同时给 fileId 和完整 URL，URL 字段名带 `Url` 后缀。
- **空值**：响应里没有值的字段输出 null。

### 1.7 实现进度说明

2026-10-08 本地功能分支已落地两个公开搜索接口，采用 ElasticsearchOperations 查询部署中的索引，不再返回未实现码。关键词、分类/类型、四种商品排序、分页、图片 URL 和错误码的验证见 [搜索 API 落地与验收](SEARCH_API.md)。本地实现不等于已合并或线上应用已更新；其他模块的历史统计不作为本次搜索验收结论。

搜索同步使用 MySQL → Logstash → ES，Java 只读。搜索不注册 MQ 队列或消费者、不发布搜索消息；应用的通用 RabbitMQ 自动配置、连接参数、JSON 转换和投递回调仍保留给其他业务。Java 搜索 sync/rebuildAll 明确禁止调用。保持 DSS_SEARCH_REBUILD_ON_STARTUP=false，错误设为 true 会启动失败且不删除索引。部署/增量维护边界见 [Logstash 部署记录](LOGSTASH_SYNC.md)。

已有实现不是验收证明：到期退款条件待修复，真实页面联调和全链路回归尚待完成。下文业务规则仍是交付要求；**路径、字段、业务码以本文档为准，实现时对齐**。进度、缺陷和验收顺序见 [PROGRESS.md](PROGRESS.md)。

## 5. 接口

### 5.1 认证与用户

#### 5.1.1 发送验证码（公开）

`POST /api/v1/auth/sms-code`

验证码不真发短信，会打印在后端日志里。

请求体：

| 字段 | 类型 | 必填 | 校验 | 说明 |
|---|---|---|---|---|
| phone | string | 是 | `^1[3-9]\d{9}$` | 手机号 |

响应 data：null

业务码：101001

```json
// 请求
{ "phone": "13800138000" }
// 响应
{ "code": 0, "msg": "ok", "data": null }
```

#### 5.1.2 登录 / 自动注册（公开）

`POST /api/v1/auth/login`

请求体：

| 字段 | 类型 | 必填 | 校验 | 说明 |
|---|---|---|---|---|
| phone | string | 是 | `^1[3-9]\d{9}$` | 手机号 |
| code | string | 是 | `^\d{6}$` | 验证码 |

响应 data：

| 字段 | 类型 | 说明 |
|---|---|---|
| token | string | 放进 `Authorization: Bearer <token>` |
| user | UserVO | 用户资料 |

业务码：101002、101003、101004

```json
// 请求
{ "phone": "13800138000", "code": "482915" }
// 响应
{
  "code": 0, "msg": "ok",
  "data": {
    "token": "3f8c1a52-7d4e-4b9a-9c1e-2a6f0e5d7b21",
    "user": {
      "id": "101486542963081217", "phone": "13800138000", "nickname": "用户8000",
      "avatar": null, "avatarUrl": null, "createTime": "2026-10-01 12:00:00"
    }
  }
}
```

#### 5.1.3 登出（登录）

`POST /api/v1/auth/logout`

没有请求体。响应 data：null。

#### 5.1.4 当前用户资料（登录）

`GET /api/v1/users/me`

响应 data：UserVO

业务码：101005

#### 5.1.5 修改昵称 / 头像（登录）

`PUT /api/v1/users/me`

传哪个字段就改哪个。

请求体：

| 字段 | 类型 | 必填 | 校验 | 说明 |
|---|---|---|---|---|
| nickname | string | 否 | 1–20 字 | 昵称 |
| avatar | string | 否 | 最多 200 字 | 头像 fileId（先调 5.2.1 上传） |

响应 data：UserVO（修改后的资料）

业务码：101005

```json
// 请求
{ "nickname": "爱吃面的小王", "avatar": "group1/M00/00/00/wKgAAmbzZ1uAcUTnAAHUH3XGd6s512.jpg" }
```

#### 5.6.8 去使用（本人订单）

`POST /api/v1/orders/{orderId}/use`

用户在订单详情页对状态为 `UNUSED` 且未到期的订单点击“去使用”，调用此接口**立即完成教学模拟核销**；无需商家扫码、输入券码或二次确认。请求须带当前登录用户的 Bearer token，没有请求体。

| 路径参数 | 类型 | 说明 |
|---|---|---|
| orderId | string | 本人的订单 ID，十进制字符串 |

- 后端从 token 获取用户 ID，校验该订单属于本人；不是本人的订单与不存在都返回 `104001`。
- 只有 `UNUSED` 且当前时间早于 `expireTime` 才能使用。已过期返回 `104005`；已经 `USED`、`REFUNDED` 或其他状态返回 `104006`。
- 成功时将订单从 `UNUSED` 更新为 `USED`，记录 `useTime`，并返回更新后的 OrderVO；重复点击不会产生第二次成功。退款与使用只能有一个状态变更成功。
- 券码继续在订单详情中展示，但接口不接收券码，券码本身不能代替登录鉴权或订单归属验证。

响应 data：OrderVO（状态为 USED，含券码与 useTime）

业务码：104001、104005、104006
