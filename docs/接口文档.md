# 接口文档

本页按远端 main `e79f349` 的 Controller、DTO/VO 和 Service 整理。记录现有行为，不以旧计划覆盖代码，也不表示接口已通过运行验收。Swagger 默认位于 `/swagger-ui.html`，OpenAPI 为 `/v3/api-docs`。

## 通用约定

- 下表省略共同前缀 `/api/v1`。公开接口不需要登录；登录接口使用 `Authorization: Bearer <token>`；内部接口使用 `X-Internal-Key`。
- JSON 响应为 `{"code":0,"msg":"ok","data":...}`。无数据时 data 为 null。图片读取成功返回图片流，不包 JSON。
- 通用错误：HTTP 400/401/403/404/500/501 对应 40000/40100/40300/40400/50000/50100。业务错误统一 HTTP 200，以 code 判断结果。
- ID 用字符串；金额为整数分；时间为 `yyyy-MM-dd HH:mm:ss`，上海时区。普通字段空值通常为 null，抢购结果的空字段省略。
- 分页参数 page 默认 1、最小 1；size 默认 10，范围 1–50。结果为 `{list,total,page,size}`。
- 搜索还要求 page × size ≤ 10000，超过返回 40000。
- 用户身份只取登录态，不接受调用者传入 userId。登录鉴权访问按配置滑动续期，默认 7 天。

## 搜索

| 方法 | 路径 | 参数 | data |
| --- | --- | --- | --- |
| GET | `/search/products` | keyword（最多 50 字）、category、type、sort、page、size | 分页 ProductHitVO |
| GET | `/search/shops` | keyword（最多 50 字）、category、page、size | 分页 ShopHitVO |

两接口公开。商品只返回 ON_SHELF 的 NORMAL；type=FLASH 返回空页。商品关键词查名称、套餐条目和店名；店铺关键词查名称和地址。空白关键词按未提供处理。

ProductHitVO：`id,name,shopId,shopName,shopCategory,type,price,soldCount,imageUrl,flashStartTime,flashEndTime`。
ShopHitVO：`id,name,address,category,coverUrl,businessHours`。

Java 仅读取 ES。同步由 Logstash 负责，没有公开重建 API。

## 订单

以下全部需要登录。只能查询和操作本人订单。

| 方法 | 路径 | 输入 | data |
| --- | --- | --- | --- |
| POST | `/orders` | `{productId}`，仅 NORMAL | `{orderId}`，同步建单 |
| POST | `/orders/flash` | `{productId,requestKey}` | FlashAcceptedVO |
| GET | `/orders/flash/result/{orderId}` | 无 | FlashResultVO |
| GET | `/orders` | status 可选、page、size | 分页 OrderListItemVO |
| GET | `/orders/{orderId}` | 无 | OrderVO |
| POST | `/orders/{orderId}/pay` | 无 | OrderVO |
| POST | `/orders/{orderId}/cancel` | 无 | OrderVO |
| POST | `/orders/{orderId}/refund` | 无 | OrderVO |
| POST | `/orders/{orderId}/use` | 无，不接券码 | OrderVO |

普通下单 productId 为 1–19 位数字字符串；抢购 productId 须为非零开头的 1–19 位数字字符串。requestKey 为 16–128 位字母、数字、下划线或短横线。同一购买意图重试必须复用键，不重复预占或延长期限。

**当前提交边界**：抢购 submit 不先将普通商品转换成 103012 错误。使用新 requestKey 提交无抢购缓存的 NORMAL 商品时，实际返回 HTTP 500 / code=50000；运行门禁未就绪时也返回该不可用错误。客户端不能依赖 103012 判断是否选错入口，NORMAL 应调用普通下单接口；50000 也不是“确定未建单”的证明，已有购买意图仍按原键和本人结果查询核对。

抢购提交示例：

```json
{"productId":"123","requestKey":"demo_request_0001"}
```

FlashAcceptedVO：`orderId,state,acceptedAt,queueDeadline`。state 为 PROCESSING，首次预占期限为 30 秒。返回不证明 MySQL 已建单。

FlashResultVO：查到本人订单时为 `{state:"CREATED",orderId,orderStatus}`；未查到或不是本人时为 `{state:"NOT_CREATED"}`。NOT_CREATED 是查询时快照，不证明请求已终止或库存已释放。查到 CREATED 后再取真实订单详情，按当前状态操作。

OrderVO：`id,productId,shopId,productType,productName,productImageUrl,shopName,amount,status,voucherCode,payChannel,createTime,payDeadline,payTime,expireTime,useTime,cancelTime,cancelReason,refundTime,refundReason`。
OrderListItemVO：`id,productType,productName,productImageUrl,shopName,amount,status,createTime,payDeadline`。

支付为模拟，默认建单后 15 分钟内可付，生成 12 位券码；支付成功时间加商品 validDays 得到券到期时间，客户端以订单 `expireTime` 为准。支付/用券会检查有效期。未付取消回补抢购库存和额度；支付后退款不回补。详细状态和故障边界见 [需求文档](需求文档.md) 和 [抢购说明](FLASH_SALE.md)。

## 内部录入

内部接口只认内部口令，不认用户 token。新建使用 POST，整体修改使用 PUT。

| 方法 | 路径 | 请求 |
| --- | --- | --- |
| POST | `/internal/shops` | ShopSaveDTO |
| PUT | `/internal/shops/{shopId}` | ShopSaveDTO |
| POST | `/internal/products` | ProductSaveDTO |
| PUT | `/internal/products/{productId}` | ProductSaveDTO |
| PUT | `/internal/products/{productId}/status` | `{status}`，成功 data=null |

ShopSaveDTO：name（非空、最多 50 字）、address（非空、最多 200 字）、category、images（1–9 个非空 fileId）必填；businessHours（最多 50 字）、phone 可选。phone 提供时须为 5–20 位数字、空格、加号或短横线。创建/整体修改成功返回 ShopVO。

ProductSaveDTO：shopId（1–19 位数字字符串）、name（非空、最多 60 字）、contents（可空数组）、price（至少 1 分）、type、image、validDays（1–365）、useRules（可空数组）必填。contents 的分组为 `{title,items:[{name,count}]}`；title 最多 30 字，项目名最多 50 字，count 至少 1；每组至少一项。useRules 每项非空、最多 50 字。

创建/整体修改成功返回 ProductVO。FLASH 还要求 stock≥1、flashStartTime、flashEndTime，结束晚于开始，limitPerUser 默认 1、最小 1。创建后不能改 type/shopId；开抢后不能改全部商品资料。NORMAL 新建上架，FLASH 新建下架。内部新建 FLASH 不代表加入当前演示轮次。

## 接口协作

路径表共 38 个端点，包含公开代理读图和本人抢购结果接口。数量不代表测试覆盖。修改接口须同步 Controller、DTO/VO、OpenAPI 和本文，PR 说明兼容性、联调与发布顺序。发现差异先核对代码，不用历史文档要求改动业务行为。
