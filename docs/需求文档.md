# 需求文档

TikCookie 是团购券教学项目。目标是展示从浏览商品到购买、模拟支付、用券和评价的完整过程。不接真实短信、支付、退款或商家核销。

代码基线为远端 main `e79f349`。下列功能有对应实现；是否可交付，仍须按 [测试说明](TESTING.md) 验证。本文不记录本地临时分支或服务器状态。

## 角色和功能

| 角色 | 需求 |
| --- | --- |
| 游客 | 浏览分类、店铺和商品；搜索普通商品和店铺；查看评价 |
| 登录用户 | 下单、查询本人订单、模拟支付、用券、取消、退款、收藏、评价和修改资料 |
| 项目组员 | 通过内部口令上传图片、录入店铺和商品、修改资料及上下架 |
| 后台任务 | 处理抢购生命周期、排队请求、支付超时和券到期 |

主路径：浏览或搜索 → 登录 → 下单 → 模拟支付 → 查看券码 → 本人点击“去使用” → 评价。

## 业务规则

- 一单一件商品、一张券。金额用整数分。API ID 用字符串。时间为上海时区。
- 普通商品同步下单。成功后返回订单 ID。
- 抢购仅支持单实例后端。Redis Lua 预占库存和个人额度；RabbitMQ 消费后事务写 MySQL。
- 抢购返回 `PROCESSING` 不代表建单成功。客户端复用同一 `requestKey` 重试，并查询本人建单结果。
- 抢购列表仅展示本轮、缓存完整、进行中、上架且仍有可预占库存的商品。开抢后商品资料不可编辑。
- 内部创建 FLASH 商品不等于加入可交易的本轮。启用抢购时，启动器追加演示商品并建立缓存。
- 支付期限默认 15 分钟。模拟支付后生成 12 位数字券码。券到期时间为支付成功时间加商品 validDays，以订单 expireTime 为准。用券只校验本人订单，不接收券码作为凭据。
- 未付订单取消或超时取消后，抢购库存和额度按幂等流程释放。支付后退款不回补库存、不释放限购额度。
- 评价要求订单已使用。一单一评，1–5 星，文字最多 500 字，图片最多 3 张，可匿名。
- 收藏支持店铺和商品。重复收藏报业务错误，取消不存在的收藏也成功。
- 图片由后端上传 OSS，数据库存对象 key，不存图片内容。只支持 jpg、png、webp，单图默认 5 MB。
- 搜索只查询 ES 中的上架普通商品和店铺；`type=FLASH` 返回空结果。抢购展示不以 ES 为准。
- Logstash 负责 MySQL 到 ES 的同步。Java 不写入或重建索引。轮询有延迟，物理删除需维护处理。

## 订单状态

| 操作 | 变化 |
| --- | --- |
| 建单 | 生成 UNPAID |
| 期限内模拟支付 | UNPAID → UNUSED |
| 用户取消或超时取消 | UNPAID → CANCELLED |
| 到期前本人用券 | UNUSED → USED |
| 用户退款或券到期退款 | UNUSED → REFUNDED |

订单归属、有效期和状态均由后端校验。重复请求不得重复修改库存和销量。

## 交付与边界

- 按 [接口文档](接口文档.md) 验证成功、错误参数、越权和重复操作。
- 单机 Linux 部署采用五服务 Compose、后端 JAR、Nginx 前端 dist。OSS 单独配置。
- 核对 MySQL 持久化、消息消费、搜索更新、图片访问、重启及备份恢复。
- 已实现、测试通过、部署成功和完整验收分别记录，不能互相替代。
- 不要求多实例、高可用、Kubernetes、真实交易、购物车、商家后台或吞吐指标。

详细抢购规则见 [FLASH_SALE.md](FLASH_SALE.md)，运行验证记录见 [TESTING.md](TESTING.md)。

### 故事与验收映射

P0 为购买主链路，P1 为配套功能，优先级只决定顺序。接口省略 `/api/v1`，完整字段见 [接口文档](接口文档.md)。

| 编号 / 优先级 | 用户故事 | 最小验收 | 主要接口 |
| --- | --- | --- | --- |
| US-01 / P0 | 游客用验证码登录，以便购买 | 演示码可用，新号注册；错误、过期和无效 token 被拒 | POST /auth/sms-code、POST /auth/login |
| US-02 / P0 | 游客浏览分类、首页和抢购，以便找到商品 | 普通列表只展示上架项；抢购只展示本轮可售项，详情 ID 对应 | GET /categories、/products、/products/flash |
| US-03 / P1 | 游客搜索和筛选，以便缩小范围 | 普通商品与店铺按约定筛选、排序和分页；失败不伪装空页 | GET /search/products、/search/shops |
| US-04 / P0 | 游客看套餐、价格和规则，以便决定购买 | 店铺、有效期可见；抢购时间、库存和限购可查；下架不可买 | GET /products/{productId} |
| US-05 / P1 | 游客查看店铺和在售商品，以便到店选购 | 店名、地址和图片可见；店内商品进入真实详情 | GET /shops/{shopId}、/shops/{shopId}/products |
| US-06 / P0 | 登录用户购买普通券，以便获得待付订单 | 一单一件，同步 ID 可查；价格和名称保存快照 | POST /orders、GET /orders/{orderId} |
| US-07 / P0 | 登录用户在时间窗内抢购，以便购买限量商品 | 预占后 PROCESSING，本人结果 CREATED 后查单；同键不重复建单；时间/库存/限购正确拒绝 | POST /orders/flash、GET /orders/flash/result/{orderId} |
| US-08 / P0 | 登录用户模拟支付，以便取得券码 | 支付截止内成功为 UNUSED，生成唯一 12 位券码，重复不加销量 | POST /orders/{orderId}/pay |
