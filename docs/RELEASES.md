## 发布验收

- [ ] 前端页面可通过统一入口访问
- [ ] 后端健康检查通过
- [ ] 登录、搜索和订单等核心流程通过
- [ ] MongoDB 数据可持久保存
- [ ] Redis、RabbitMQ、Elasticsearch 和 OSS 的实际业务链路通过
- [ ] 当前前后端提交 SHA 可确认
- [ ] 上一成功版本可定位并具备回退条件

> 不在本文档中记录密码、Token、AccessKey 或其他敏感配置。
