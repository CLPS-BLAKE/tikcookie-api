## 2. 常规检查

使用 JDK 21，在后端仓库根目录执行：

```bash
mvn -B --no-transfer-progress clean verify
```

前端在自己的仓库运行 `npm ci`、`npm run build`。保存两个提交 SHA、运行时版本、退出码、测试通过/失败/跳过数及告警摘要。CI 工作流定义不是一次成功运行的证据。

现有后端测试主要覆盖公共响应、校验、异常、鉴权、时间、ObjectKey、URL、文件接口和搜索。隔离配置的应用启动测试不等于真实系统启动；不能从这些测试推断订单、抢购或前端均已验收。

## 3. 显式真实依赖测试

默认构建不执行真实 OSS、MQ、ES 联调。下列开关必须在进程环境显式启用，只对获准的隔离环境运行。

| 开关 | 测试类 | 影响 |
| --- | --- | --- |
| `DSS_ES_LIVE_TEST=true` | `SearchApiEsLiveTest` | 读取真实索引，依赖稳定数据和匹配映射 |
| `DSS_OSS_LIVE_TEST=true` | `OssFileStorageLiveTest` | 真实对象操作，先核对 Bucket 和权限 |
| `DSS_RABBIT_LIVE_TEST=true` | `SearchSyncPublisherRabbitLiveTest` | 历史发布器联调，可能投递消息；不证明当前搜索使用 MQ |

例如设置进程开关后执行 `mvn -B -Dtest=SearchApiEsLiveTest test`，结束后清除开关。只将开关写入 `.env` 不等于启用测试。

## 4. 核心验收清单

| 场景 | 必须观察的结果 |
| --- | --- |
| 配置和启动 | 缺配置可定位；端口受控；不泄露凭据；记录启用抢购是否追加新轮 |
| 登录 | 演示验证码、新号注册、错误/过期码、发送频率、token 续期和退出 |
| 鉴权 | 未登录 401；错误内部口令 403；不能操作他人订单；详情携带无效 token 被拒 |
| 浏览和录入 | 内部上传及店铺/商品创建、更新、上下架；列表、详情与数据库一致 |
| 普通订单 | 同步返回真实 ID；本人详情可查；金额、名称、支付截止正确 |
| 抢购 | 预占后 PROCESSING；本人结果 CREATED 后查真实订单；同键重试不重复预占或建单 |
| 抢购边界 | 未开始、结束、售罄、限购；旧轮不可售；内部新建 FLASH 不自动加入本轮 |
| 订单状态 | 支付、取消、退款、用券及重复操作；超期支付/用券拒绝；库存和销量只变更一次 |
| 任务和消息 | 异步消费、重复消息、支付超时、到期退款；已过期才退；记录失败与暂停商品 |
| 收藏和评价 | 收藏增删/列表/状态；一单一评、已使用才评、匿名和图片限制 |
| 搜索 | 普通商品/店铺查询、筛选、排序、分页；FLASH 空结果；故障返回 107001 |
| Logstash | 增量、上下架、店铺关联更新、字段/时区、游标重启恢复；核对物理删除限制 |
| OSS | 上传、对象存在、URL 可访问、业务绑定；公共读和代理模式分别验证 |
| 部署 | Nginx 首页/API/拒绝内部入口；数据持久化、应用重启、备份恢复与回退 |
