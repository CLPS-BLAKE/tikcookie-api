## 4. 前端状态

Vue 3 + Vite + Vant + Vue Router + Axios 工程、锁文件和 `/api` 代理已有。实际组件库为 Vant，而非历史方案中的 Element Plus。已有 10 个页面路由：登录、首页、搜索、商品详情、店铺、支付、成功、券详情、个人中心/订单、评价。

| 功能 | 当前状态 | 缺口 |
|---|---|---|
| 请求基础 | `/api/v1`、Bearer token、错误提示、401 处理 | 全业务接口接入 |
| 登录 | 已调用验证码/登录接口 | 失败时自动写假 token 并提示成功，不能算真实登录验收 |
| 浏览 | 首页/商品/店铺和跳转已有 | 大多硬编码，详情跳转不带真实 ID |
| 搜索 | 输入、历史/推荐样例已有 | 未请求真实搜索，缺结果/筛选/分页 |
| 交易 | 支付/成功/券页面已有 | 下单、支付、取消、退款、去使用未接真实状态变更 |
| 用户/收藏 | 个人中心展示已有 | 订单列表/状态、资料、头像上传、收藏管理待接通 |

证据：前端 `src/router/index.js`、`src/api/user.js`、`src/utils/request.js` 及页面脚本。评价、配送、购物车和复杂优惠原型不自动成为本期需求。
